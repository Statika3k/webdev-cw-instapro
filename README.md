# Instapro — учебный проект

Простое веб-приложение для публикации и просмотра постов с возможностью лайков (аналог Instagram).

## 📱 Функциональность

### ✅ Реализованная базовая функциональность

- **Просмотр общей ленты постов** — доступен всем пользователям (авторизованным и неавторизованным)
- **Просмотр ленты постов конкретного пользователя** — переход по клику на аватар или имя автора
- **Регистрация нового пользователя** — с именем, логином, паролем и аватаром
- **Авторизация существующего пользователя** — по логину и паролю
- **Добавление нового поста** — с описанием и изображением (только для авторизованных)
- **Лайки и дизлайки** — авторизованные пользователи могут ставить/снимать лайки без перезагрузки страницы
- **Выход из аккаунта** — через кнопку в шапке
- **Форматирование даты** — отображение времени публикации в формате «N минут/часов/дней назад» на русском языке
- **Безопасность** — экранирование HTML-тегов в описании поста для защиты от XSS-атак
- **Адаптивный интерфейс** — базовая поддержка мобильных устройств
- **Индикаторы загрузки** — при выполнении асинхронных операций

## 🚀 Дополнительные улучшения

Помимо базовых требований, были реализованы следующие улучшения:

- **Возможность удаления собственных постов** — кнопка «Удалить» отображается только у постов текущего авторизованного пользователя, с подтверждением через confirm()
- **Анимация кнопки лайка** — плавное увеличение при наведении (`transform: scale(1.1)`) и эффект «нажатия» при клике (`transform: scale(0.95)`)
- **Плавные переходы между страницами** — добавлена CSS-анимация `fadeIn` для контейнера страницы
- **Локализация даты** — отображение времени на русском языке с помощью `date-fns`
- **Полная защита от XSS** — с помощью функции `sanitizeHtml`
- **Визуальная обратная связь** — индикация загрузки при операциях с лайками
- **Кэширование данных пользователя** — сохранение сессии в localStorage

## 🛠 Технологии

- **Frontend**: Vanilla JavaScript (ES6+), CSS3, HTML5
- **Роутинг**: SPA с клиентской маршрутизацией
- **API**: REST API с Bearer-аутентификацией
- **Библиотеки**: date-fns для работы с датами
- **Безопасность**: Кастомная XSS-защита, валидация ввода

export function sanitizeHtml(value) {
  return value
    .replaceAll('&', '&amp;')
    .replaceAll('<', '&lt;')
    .replaceAll('>', '&gt;')
    .replaceAll('"', '&quot;')
    .replaceAll("'", '&#039;')

};
